# Step 6: Motion (Code!!) ```csharp using UnityEngine; using UnityEngine.InputSystem; public class PlayerController : MonoBehaviour { void Start() { } void FixedUpdate() { } void OnMove(InputValue movementValue) { } } ``` # Step 6: Motion (Imports) ```csharp using UnityEngine; using UnityEngine.InputSystem; ``` # Step 6: Motion (Properties) ```csharp public class PlayerController : MonoBehaviour { public float speed = 10; // Gains editor controls private Rigidbody rb; private float movementX; private float movementY; ... ``` # Step 6: Motion (Init) ```csharp void Start() { rb = GetComponent(); } ``` # Step 6: Motion (Input) ```csharp void OnMove(InputValue movementValue) { Vector2 movementVector = movementValue.Get(); movementX = movementVector.x; movementY = movementVector.y; } ``` # Step 6: Motion (Physics) ```csharp void FixedUpdate() { Vector3 movement = new Vector3(movementX, 0.0f, movementY); rb.AddForce(movement * speed); } ``` # Step 6: All together now Use WASD or arrow keys to control the ball. # Step 7: Walls and prefabs
